# Week 03 · Social LSTM 中的邻居信息有用吗？

**本次教学设置未显示邻居信息的稳定收益。** 基于教师代码包，对原始 4 m 网格、屏蔽邻居、缩小至 2 m、扩大至 8 m 四种配置分别训练。三个随机种子的平均测试 ADE 中，屏蔽邻居优于原始模型，但并非每个种子都改善；四种 LSTM 均明显弱于匀速外推。这是一次小样本机制对照，不是对 Social LSTM 方法普遍有效性的判断。

## 改了什么，邻居如何进入模型

教师实现将邻居相对位置映射到以行人为中心的 4×4 网格，把邻居的 32 维 LSTM 隐藏状态压缩成 8 维并填入格子；展开后的 128 维网格嵌入为 32 维，与自身速度的 16 维嵌入拼接，再更新 LSTM。预测输出二维速度分布的均值，并逐步累加为未来坐标。目标位置分支关闭。

所有配置保留相同网络形状和 **25,633 个参数**；修改不叠加，每种都从头训练：

- **原始 Social / 4 m：** 单格边长 1 m，总边长 4 m。
- **屏蔽邻居：** 嵌入前输入全零网格，仍保留池化网络和可训练偏置；偏置不携带邻居信息。被屏蔽支路的部分参数不再收到数据梯度，所以参数总量相同不意味着所有参数仍有效参与学习。
- **Social / 2 m：** 单格改为 0.5 m，总边长 2 m。
- **Social / 8 m：** 单格改为 2 m，总边长 8 m。

修改入口是 [experiment.py](model/experiment.py) 的 `NeighbourPooling.forward` 与 [config.json](model/config.json)。范围实验固定格数，因此同时改变了物理单格大小，不能解释为单独隔离了“距离范围”的因果作用。教师源码同格多人采用索引赋值，存在覆盖，**并非标准求和池化**；这次保留原实现作为共同基线。

## 公平比较与预测协议

直接使用教师包的三份 NDJSON，逐字节校验。原始 TXT 与第二周完全相同；按前述 Xiao 等（2018）实验设置使用 25 fps、厘米转米，采样间隔 2 帧。因此 8 个观测点首尾相隔 **0.56 s**，12 步预测覆盖 **0.96 s**，不是常见基准的 3.2/4.8 s 设置。

按时间先分 60%/20%/20%，再截窗。训练/验证/测试分别为 56/12/12 个场景，原始帧区间分别为 37–289、291–375、377–461，不共享帧。主要预测对象固定为 ID 1、17、33、49，其余 63 人作为潜在邻居。测试集只有 **3 个时间窗口 × 4 个主要行人**，同一集合内窗口重叠，不能把 12 个场景视为独立实验。

共同条件：种子 42/43/44，每组实际训练 10 轮，batch=2，Adam 学习率 0.001、weight decay=0.0001，StepLR 第 10 轮后衰减，无数据增强；CPU 两线程。每个种子下，四种配置的初始参数哈希和每轮样本顺序完全相同。所有 12 组训练和验证共约 10.9 分钟，记录见 [training.json](results/training.json)。

训练沿用教师的概率损失、真实邻居未来的 teacher forcing 和训练期远邻筛选。**验证与测试仅把 8 点历史传入模型，保留全部 64 人；所有人的未来均由模型递推，不用真实未来筛选邻居，也不输入真实目标。** 每轮按这种历史输入协议计算验证 ADE，取最低者保存权重；跨种子的平均验证 ADE 用于确定展示方案。全部选择固定后才计算正式测试指标。一次单轮代码检查仅用于确认接口可运行，未用于调整配置。

采用单次均值轨迹，计算主要行人在 12 个未来点的欧氏距离均值 ADE，以及第 12 点的 FDE；先算每个场景，再等权汇总。没有使用 best-of-K，也没有把训练 loss 当成 ADE/FDE。

## 结果与解释

下表为三个种子的均值 ± 样本标准差，单位 m；标准差反映初始化差异，不是置信区间。匀速外推不训练，无种子标准差。

| 配置 | 验证 ADE | 测试 ADE | 测试 FDE |
|---|---:|---:|---:|
| 原始 Social / 4 m | 0.494 ± 0.023 | 0.614 ± 0.058 | 1.205 ± 0.150 |
| 屏蔽邻居 | **0.441 ± 0.036** | **0.554 ± 0.046** | **1.119 ± 0.073** |
| Social / 2 m | 0.531 ± 0.019 | 0.692 ± 0.053 | 1.322 ± 0.082 |
| Social / 8 m | 0.484 ± 0.082 | 0.675 ± 0.102 | 1.299 ± 0.168 |
| 匀速外推 | 0.237 | 0.125 | 0.234 |

屏蔽邻居相对原始模型的平均测试 ADE 减少 0.059 m，约 **9.7%**；ADE/FDE 都是 2/3 个种子改善。缩小邻域在三个种子上均变差；扩大邻域仅一个种子改善，平均表现也变差。不能据此声称“邻居越少必然越好”。

轨迹图固定展示第一测试窗口的四个目标，使用种子 42，没有挑选最好看的样本。场景 68 中，屏蔽邻居使 ADE 从 0.658 降到 0.556 m；场景 70 则从 0.531 升到 0.540 m。两者都仍有明显轨迹偏差，完整结果见 [per_scene.csv](results/per_scene.csv)。

误差的一个合理解释是运动阶段变化：四个目标在训练、验证、测试窗口中的平均逐步速度约为 **1.84、1.15、0.24 m/s**，测试后段含较多慢行、停步。图中学习模型经常继续预测前进，短期匀速外推更贴近这批后段数据。4 m 网格在观测历史中的平均候选邻居数，也由训练的 6.49 变为测试的 3.50。统计定义与明细见 [split_diagnostics.csv](results/split_diagnostics.csv)、[neighbour_audit.csv](results/neighbour_audit.csv)。这些是解释线索，不能单独证明误差由哪一个因素造成。

**一段结论：** 在同一时间划分、同一 8+12 预测窗口和相同训练预算下，教师版 Social LSTM 加入或扩大邻居网格，没有获得稳定的短期预测增益；全零邻居网格取得较低平均误差，但仍不及匀速外推。当前结果提示，邻居信息的价值取决于有效汇总方式、训练阶段覆盖和模型是否学会减速停步，不能仅由“输入更多邻居”保证。由于数据只有单次圆环实验、四个主要目标和三个测试时间窗口，且训练仅 10 轮、池化存在同格覆盖，本结论限于本课堂设置，不能推广为社会交互信息普遍无用。

## 复现、检查与文件

在仓库根目录，使用独立 Python 3.9/3.10 环境；本机实际为 Python 3.9.23、PyTorch 2.5.1，其他依赖固定在 [requirements.txt](requirements.txt)。例如先创建并激活环境，再运行：

```bash
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r week03/requirements.txt
python -X utf8 -m week03.model.run --evaluate-only
python -X utf8 -m week03.model.plots
```

已提交的 12 份权重无需重训即可复核。重新训练与重画到独立目录：

```bash
python -X utf8 -m week03.model.run --output .local/week03_retrain
python -X utf8 -m week03.model.plots --results .local/week03_retrain
python -m pip install pytest==8.4.2
python -m pytest -q tests/test_week03_model.py
```

九项自动检查覆盖：同初始权重、原始池化一致性、屏蔽后邻居不影响目标、仅历史预测接口、排除自己及远邻、源码/数据哈希、划分与目标一致性、ADE/FDE 定义，以及保存权重、预测数组和验证选轮互相一致。

`model/` 放配置、修改代码、教师核心源码和固定数据；`results/` 放三张 PNG、12 份小型权重、预测 NPZ、逐轮/逐场景指标和审计记录。PDF/SVG 在本地导出，不重复放入 Git。未纳入教师包中无关的 GAN/VAE、其他数据集和宣传图片。

源码引用、MIT 许可证、实际依赖变化和 AI 辅助范围见 [SOURCE.md](model/SOURCE.md)。使用 Codex（GPT-6）辅助阅读、实现、运行、检查、绘图及整理说明；报告数值全部来自本次实际训练。
