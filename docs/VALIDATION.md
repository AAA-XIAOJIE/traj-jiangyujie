# Week 01 验证记录

## 数据与几何

- 25 个上游文件通过固定 SHA-256 核验。
- 五场景合计 1,536 个场景内轨迹 ID、25,126 个原生标注点。
- 保留 23,453 条相邻点连线，断开 137 个超过默认 UCY 时间阈值的区间。
- 每个个体均满足 `标注点数 - 连续分量数 = 已绘制连线数`；长间隔和孤立点没有从标准化表格中删除。
- ETH 与原 `obsmat.txt`、UCY 与像素坐标和 H 的坐标一致性核验通过。详细数值见 `week01/results/run_receipt.json`；这不是独立定位误差测试。

## 自动检查

`python -m pytest -q`：11 项测试通过。覆盖源矩阵 x/y 对应、时间基准、异常输入拒绝、跨人隔离、排序、ETH 间隔断线、UCY 不等间隔边界、时间窗裁剪、窗口选取、下载路径边界及哈希篡改检测。

`python -m pip check`：依赖关系无错误。

`python scripts/verify_release.py`：18 个图件、PNG 尺寸、SVG 文本/路径、PDF 文件结构、数据总量守恒及 Markdown 本地链接检查通过。该命令写出 `week01/results/artifact_checks.json`。

`git diff --cached --check`：通过。生成文本统一使用 LF，下载的原始文件保留字节不变。

## 视觉检查

总览图和五张单场景图均已查看。检查项目包括文字与坐标轴完整、1:1 坐标比例、统一空间跨度、时间色条含义、全场景/细节区分，以及断线后的孤立点显示。单场景图的轴标签与时间色条之间已留出独立空间。

PNG 用于视觉检查，PDF 和 SVG 由同一 Matplotlib 图形对象导出；矢量文件另做结构与文本可编辑性核验。没有把照片注册或视频内容作为本周验证的一部分。
